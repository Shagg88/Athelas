# Athelas 1.8.1

Press **Update** in the launcher, or unzip it over your Athelas folder: your settings, saves and achievements are
kept.

## New

- **ROTKPlus mod** for The Return of the King (PC), by brig-dev: co-op for 3 and 4 players, a Versus mode for up to
  4, and a name and statistics for each player. It is **off by default**: turn it on in the launcher's **Mods** tab.
  Questions and bugs about ROTKPlus go to https://github.com/brig-dev/ROTKPlus (#29, #63).

## Fixed

- **Launcher**: cleaning up old builds no longer follows folder links (junctions), so it can't touch a folder outside
  Athelas.
- **Launcher**: a save backup now stops with a clear message if a folder can't be read, instead of saying it worked
  while leaving files out.
- Each mod's licence is now included in the download (ROTKFix\licenses).
