# Athelas 1.9.3

A small update to help track down the bugs that are hard to reproduce.

Update with the launcher's **Update** button. Your settings, saves and achievements are kept.

## New

- **Logging levels** for the four Xbox games (Gameplay tab, under More; also in the in-game menu):
  - **Normal**: your settings, your PC and problems only, as before.
  - **Detailed**: also every button and key you press (with the time), every game file opened, and the notes that
    say which fixes are at work. Use it for a bug that depends on what you pressed.
  - **Full diagnostic**: everything, with frame counts and the slowest frame each second, and every line saved at
    once so a crash loses nothing. Logs get large and the game may run a little slower; set it back to Normal
    afterwards.

  Pick a level, make the bug happen, then use **Report a problem** in the launcher.
  In online co-op, the joining PC uses the host's settings, so the host's logging level applies to both; each log
  shows that PC's own presses.
