# ROTK Xbox port: working folder

The Return of the King (Xbox, US) recompiled to a native PC exe with XboxXBE-Recomp.

- `rotkxbox\`: the game repo. Run `build.bat` there. The SDK copy is `rotkxbox\sdk`.
- `notes\rotkx-01-bringup.md`: what has been done and what's next. Start here.
- `sdk_5558\`: ROTK's SDK changes as a patch over the Two Towers SDK, and the hand-proven addresses.
- `tools\`: the analysis scripts (copied from the Two Towers project).
- `extracted\`: the game files, from your own disc. Never commit or share them.

Local only: nothing goes to GitHub until you say so. No game data or generated code in any repository.
